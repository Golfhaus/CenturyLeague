# Halftime decision-quality review

Frozen policy, new targeted contexts, fresh naturally played histories. The policy source is unchanged from restored-halftime-policy-v1. No official engine, tournament runner, roster or coach is edited.

The fixed plan is docs/halftime-decision-quality-plan-2026-11-17.json. Forty-eight synthetic profiles cover twelve contexts and four original independent roster templates; eight fresh seeds per profile give 384 paired cases/768 full matches. Focal orientation alternates, the opponent holds, and focal policy is compared against Hold. The first half must match exactly. Trial zero of each profile/arm receives an exact replay (96 outcomes). Four separate preflight outcomes and all historical outcomes are excluded. Qualified runtime is Node v24.22.1 --no-maglev, with two workers, eight-case chunks, a 900-second chunk deadline and no automatic retries/seed replacement/sample extension.

Personnel fit uses symmetric +/-2 changes to three aerial and three ground-route ratings. Other contexts vary opposing tactics or +/-0.35 overall opponent quality. Workload contexts use stamina2/recovery1 with either35 eligible or20 eligible players; the full35-player roster is retained and absences use explicit synthetic availability evidence. All physics, intervals, substitutions and injury rules remain native. These are within-match fatigue tests, not cross-match carry-over or official injury claims. Tactics and fit labels do not assert an oracle of the best action.

Run make-plan.mjs with the exact original adverse-data reproduction/profiles.json input in a new checkout without a plan/profiles output, or use the frozen generated profiles from the data bundle. Original source input SHA256 is retained in profiles.json. Generated data is excluded from Git; the report bundle preserves exact bytes.

Use scripts/supervise-engine-study.py around the historical review, run, audit, analysis, packaging and delivery stages. Run audit.mjs after preflight before validation. Run analyze.mjs and independent recompute.py only after full ledger verification. Scientific outcomes are immutable; use the original recorded identities for explicit resume. Do not rerun to repair a failed download.

The primary estimate is the average pre-match focal policy-minus-Hold win probability on the fixed targeted matrix, including no-ops. A prospectively fixed conservative 95% Hoeffding bound allows heterogeneous independent streams. Context, recipe and orientation splits are descriptive. Historical selected-loss review is retrospective and cannot establish expected action harm. No thresholds or costs may be tuned to these outcomes; no minimum adoption or positive win-rate target is imposed.
